# 智慧仓库库位建模与拣料动线优化系统 (WMS)

本项目是一个基于 TypeScript 全栈开发的 WMS（仓库管理系统）原型。实现了仓库网格与库位属性配置、基于优先级的库存自动分配，以及受单行道约束的拣料动线生成与 2D 可视化展示。

## 🌟 核心功能
1. **仓库建模**：10x10 网格，支持地堆区 (FLOOR，双向)、高架区 (RACK，单向强制约束)。
2. **优先扣减算法**：优先从 `pickingPriority` 高的库位扣减；同优先级按距离升序，减少拣料动线。
3. **TSP 路径优化**：将仓库建模为有向图，通过 BFS 预计算最短路，使用状态压缩动态规划求解访问所有扣减点并返回起点的最优合法路径。
4. **2D 可视化演示**：SVG 实时渲染网格、库存状态、单行道箭头，支持拣料路线绘制与移动小车动画播放。

## 💻 技术栈
- **前端**: React 18 + TypeScript + Vite + SVG
- **后端**: Node.js + Express + `node:sqlite` (内置数据库模块，零编译依赖)
- **算法**: 排序算法、图论 BFS、状态压缩 DP (TSP)
